# Pokémon Ubers Battle Simulator

A text-based Pokémon battle simulator written in Python that recreates competitive-style Ubers battles against CPU-controlled opponents.

## Features

* 6v6 Pokémon battles
* Elo rating progression system
* Team builder and save system
* Type effectiveness calculations
* Status effects
* Entry hazards
* Choice items
* Abilities and held items
* Persistent player data using JSON
* Randomized CPU opponents
* Team preview and lead selection

## Technologies Used

* Python
* JSON
* Object-Oriented Programming

## Concepts Demonstrated

* Class design
* Data persistence
* Game state management
* Turn-based battle systems
* Probability and random events
* Algorithmic decision making

## How to Run

python pokemon.py
